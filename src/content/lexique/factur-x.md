**Factur-X est un format de facture « hybride » : un PDF que vous ouvrez comme d'habitude, avec à l'intérieur un fichier de données que les logiciels lisent automatiquement. C'est l'un des formats acceptés pour la facture électronique ; vérifiez sur les sites officiels ceux qui sont admis dans votre cas.**

## À quoi ça sert ?

Un PDF classique est une image : un humain le lit, un logiciel ne le comprend pas vraiment. Pour traiter une facture sans ressaisie, il faut des données structurées : qui facture qui, quel montant, quel taux de TVA, quelle échéance, rangés dans des champs précis.

Factur-X répond à ce besoin avec une idée simple : un seul fichier, deux niveaux de lecture. Le PDF reste présentable et archivable. Les données, intégrées dans ce même fichier, permettent à un outil de comptabilité ou à une plateforme de reconnaître automatiquement chaque information.

## Comment ça marche (en pratique)

Un fichier Factur-X est un PDF dans lequel est incorporé un fichier au format XML, un langage de balisage qui range les données dans des champs. Vous ne voyez pas ce second fichier, mais il voyage avec le PDF.

Le format a été conçu en France et en Allemagne, dans une approche commune. Il existe en plusieurs profils, du plus léger au plus complet. Plus le profil est riche, plus la facture contient de données détaillées. Le choix du profil dépend de ce que votre client ou la plateforme attend.

Dans la pratique, vous ne fabriquez pas ce fichier à la main : votre logiciel de facturation ou la plateforme que vous utilisez le génère à partir des informations que vous saisissez. Pour vous, la nouveauté se résume à :

- bien renseigner **tous les champs** (identifiants d'entreprise, adresses, taux de TVA) ;
- vérifier que votre outil sait **produire** ce format ou l'un de ses équivalents ;
- conserver ces fichiers comme toute facture.

D'autres formats structurés existent à côté de Factur-X. Les listes de formats admis et leurs règles sont publiées par l'administration ; consultez-les, car elles peuvent évoluer.

## Exemple concret

Exemple type : une boulangère facture régulièrement un traiteur. Avec son logiciel, elle saisit la facture une fois ; l'outil génère un fichier Factur-X. Le traiteur reçoit le PDF, que son assistante peut ouvrir et archiver, et son logiciel comptable lit les montants et propose directement l'écriture. Personne ne retape les lignes.

## Ce qu'il faut vérifier

- **Un PDF envoyé par e-mail n'est pas un Factur-X.** Seul un PDF qui embarque le fichier de données l'est.
- **Votre logiciel actuel** : exporte-t-il ce format ? Demandez-le à l'éditeur, par écrit.
- **La cohérence entre le PDF et les données** : elles doivent dire la même chose, sinon la facture peut être rejetée.
- **Le profil attendu** par votre plateforme ou votre client.
- **L'archivage** : gardez le fichier complet, pas seulement un aperçu.

Ne payez pas un outil uniquement pour son « compatible Factur-X » affiché en première page : testez l'envoi d'une facture réelle avec la plateforme que vous comptez utiliser.

## Questions fréquentes

**Factur-X, c'est la même chose que PDF ?**
Non. L'apparence est identique, mais un Factur-X contient en plus des données structurées. Un PDF ordinaire n'en contient pas.

**Dois-je créer le fichier moi-même ?**
Non. Un logiciel de facturation ou une plateforme le génère. Votre rôle est de renseigner correctement les informations.

**Est-ce le seul format possible ?**
Non, d'autres formats structurés existent. Consultez la liste officielle sur impots.gouv.fr pour savoir lesquels sont admis.

**Le format convient-il aux micro-entrepreneurs ?**
Oui, le format ne dépend pas de la taille de l'entreprise. Ce sont les dates d'obligation qui varient : à vérifier sur les sites officiels.
