**La meta description est le résumé d'une page, écrit dans son code, que Google affiche souvent sous le titre dans les résultats. Pour vous, c'est votre phrase d'accroche face au concurrent juste en dessous : elle sert à faire cliquer, pas à faire monter la page.**

## À quoi ça sert ?

Google a indiqué que la meta description n'est pas un critère de classement. Son intérêt est ailleurs : elle décide l'internaute. Entre deux résultats équivalents, celui dont la description explique clairement ce que l'on va trouver (et pourquoi c'est pour soi) obtient plus de clics.

Plus de clics à classement égal, c'est plus de visiteurs sans rien changer d'autre : c'est pour cela qu'elle vaut le coup d'être écrite à la main.

## Comment ça marche (en pratique)

Elle s'écrit dans une balise du code (`<meta name="description" content="…">`) ou dans un champ prévu à cet effet par votre site.

Quelques repères :

- Environ cent cinquante caractères : au-delà, l'affichage est coupé. C'est un ordre de grandeur, pas une limite fixée par Google.
- Une phrase ou deux qui annoncent le contenu et un bénéfice concret : intervention rapide, devis gratuit, conseils pratiques.
- Reprenez naturellement l'expression recherchée : Google met en gras les mots tapés par l'internaute.
- Une description différente par page.

Google ne l'utilise pas toujours. Il peut afficher à la place un extrait du texte de la page qui colle mieux à la requête. C'est normal et ce n'est pas une erreur de votre part.

## Exemple concret

Exemple type : un caviste d'Indre-et-Loire écrit pour sa page « coffrets cadeaux » : « Coffrets de vins de Loire pour offrir : sélection du caviste, message personnalisé, retrait en boutique ou envoi. » Le visiteur sait tout de suite ce qu'il va trouver et comment récupérer sa commande. À l'inverse, une description vide laisse Google composer un extrait au hasard du texte.

## Les erreurs fréquentes

- Laisser la description vide ou générée automatiquement avec la même phrase sur tout le site.
- Copier le début de la page : l'extrait n'apporte alors rien au titre.
- Écrire un texte long, coupé en plein milieu de phrase.
- Faire des promesses que la page ne tient pas (« le meilleur prix », « numéro un »).
- Bourrer la description de mots-clés au détriment de la lisibilité.

## Questions fréquentes

**La meta description améliore-t-elle le classement ?**
Non, Google a déclaré qu'elle ne sert pas au classement. Elle améliore en revanche le taux de clic, donc le nombre de visiteurs pour une même position.

**Quelle longueur viser ?**
Autour de cent cinquante caractères. Au-delà, Google risque de couper la fin ; en dessous de quatre-vingts, la description manque souvent d'information.

**Pourquoi Google n'affiche-t-il pas ma description ?**
Il choisit parfois un autre passage de la page, mieux adapté à la requête tapée. Une description précise et propre à la page est choisie plus souvent.

**Faut-il en écrire une pour chaque page ?**
Idéalement oui, au moins pour les pages importantes : accueil, prestations, contact. Une description commune à toutes les pages n'a aucune valeur.
