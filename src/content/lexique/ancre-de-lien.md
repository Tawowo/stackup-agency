**L'ancre d'un lien est le morceau de texte sur lequel on clique. Pour vous, c'est une petite étiquette qui dit où mène le lien : bien rédigée, elle aide le lecteur à décider de cliquer et donne à Google une indication sur la page visée.**

## À quoi ça sert ?

Dans « découvrez notre [installation de climatisation à Tours] », le texte entre crochets est l'ancre. Pour un lecteur, elle annonce la suite. Pour Google, elle apporte un indice sur le sujet de la page de destination : un lien dont l'ancre est « cliquez ici » n'apprend rien, alors qu'une ancre descriptive aide à situer la page.

Elle est aussi importante pour l'accessibilité : les lecteurs d'écran peuvent lister tous les liens d'une page, ce qui n'a de sens que si chaque ancre se comprend seule.

## Comment ça marche (en pratique)

On rencontre plusieurs types d'ancres.

- **Descriptive** : « devis pour une rénovation de salle de bain ». Elle décrit la destination.
- **Nom de marque** : « Stackup Agency ». Typique des liens venant d'autres sites.
- **Adresse brute** : le lien affiche l'URL elle-même.
- **Générique** : « cliquez ici », « en savoir plus ». À éviter autant que possible.
- **Image** : quand le lien est porté par une image, c'est le texte alternatif ([balise alt](/lexique/balise-alt)) qui joue le rôle d'ancre.

Sur son propre site, on a la main sur les ancres du [maillage interne](/lexique/maillage-interne). Pour les liens venant d'ailleurs ([backlinks](/lexique/backlink)), on ne contrôle pas l'ancre : et un profil où toutes les ancres sont identiques paraît artificiel.

## Exemple concret

Exemple type : un coiffeur écrit dans son blog « Pour une coloration végétale, voir cliquez ici ». Il réécrit : « Pour une coloration sans ammoniaque, découvrez [notre prestation de coloration végétale] ». Le lecteur sait où il va ; la page de destination reçoit un signal clair sur son sujet.

## Les erreurs fréquentes

- Utiliser « cliquez ici » ou « lire la suite » partout.
- Mettre la même expression exacte (le mot-clé visé) en ancre de tous les liens : cela ressemble à de la manipulation.
- Écrire des ancres trop longues, qui forment une phrase entière.
- Lier l'image sans texte alternatif : l'ancre est alors vide pour un lecteur d'écran.
- Changer le sens : une ancre qui promet un tarif quand la page ne le donne pas déçoit le visiteur.

## Questions fréquentes

**Faut-il toujours mettre un mot-clé dans l'ancre ?**
Non. Une ancre naturelle et descriptive suffit. Forcer le mot-clé partout paraît artificiel et ne rend pas service au lecteur.

**Quelle longueur pour une ancre ?**
Quelques mots, assez pour comprendre la destination. Évitez les phrases entières.

**Comment choisir l'ancre d'un lien que quelqu'un fait vers moi ?**
Vous ne contrôlez pas toujours ce choix. Si on vous le demande, proposez votre nom ou une formulation descriptive simple plutôt qu'une expression marketing.

**Le texte d'un bouton peut-il servir d'ancre ?**
Oui. Un bouton « Demander un devis pour une toiture » est plus clair qu'un simple « Envoyer » ou « Valider ».
