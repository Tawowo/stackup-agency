**Le code APE (activité principale exercée) est un code attribué par l'Insee pour classer l'activité principale de votre entreprise. Il est aussi appelé code NAF, d'après la nomenclature d'activités française. Il sert à des fins statistiques et administratives ; il ne vous autorise ni ne vous interdit une activité à lui seul.**

## À quoi ça sert ?

Le code APE aide l'administration, les organismes sociaux et les statistiques publiques à ranger les entreprises par secteur. Il peut apparaître sur vos documents, dans les registres publics, parfois sur des courriers de caisses ou de banques.

Ce qu'il **ne fait pas** : il ne définit pas à lui seul la convention collective applicable, vos obligations réglementaires, ni les activités que vous pouvez légalement exercer. Certaines professions exigent des diplômes ou des inscriptions spécifiques, quel que soit le code.

## Comment ça marche (en pratique)

- Il est attribué à l'immatriculation à partir de l'activité que vous déclarez.
- Il comprend des chiffres suivis d'une lettre, selon la nomenclature en vigueur. La nomenclature a été révisée récemment : les codes peuvent avoir été renumérotés. À vérifier sur le site de l'Insee et sur service-public.fr.
- Pour le trouver : avis de situation Insee, extrait d'immatriculation, Annuaire des entreprises.
- Si votre activité réelle ne correspond plus à votre code, vous pouvez demander une modification. Faites-le par le guichet des formalités plutôt que de laisser un code faux en place.
- Il apparaît à côté du [SIREN](/lexique/siren) et du [SIRET](/lexique/siret) dans les fiches publiques.

Pour un site vitrine, il est rarement obligatoire de l'afficher ; vos [mentions légales](/lexique/mentions-legales) reposent d'abord sur le SIRET et le statut.

## Exemple concret

Exemple type : une photographe commence par vendre des tirages, puis ajoute des prestations de formation. Son code APE reste celui de sa première activité. Elle consulte l'Annuaire des entreprises, constate le décalage et s'informe auprès du guichet des formalités sur la marche à suivre. Elle vérifie en parallèle ses obligations selon ses nouvelles activités.

## Les erreurs fréquentes

- Croire que le code APE limite ou autorise automatiquement une activité.
- Le confondre avec la convention collective ou avec le régime social.
- Laisser un code obsolète après un changement d'activité principale.
- Chercher à « bien choisir » son code pour des effets fiscaux ou sociaux supposés : renseignez-vous auprès de la source officielle.
- Recopier le code d'un confrère sans vérifier sa correspondance avec votre activité.

## Questions fréquentes

**Code APE et code NAF, c'est la même chose ?**
Oui en pratique : « APE » désigne l'activité principale exercée, « NAF » la nomenclature qui fournit les codes.

**Où trouver mon code APE ?**
Sur l'avis de situation Insee, l'extrait d'immatriculation ou l'Annuaire des entreprises.

**Puis-je changer de code APE ?**
Si votre activité principale a changé, oui, par une démarche de modification. Les modalités sont indiquées sur service-public.fr.

**Le code APE influe-t-il sur mes cotisations ?**
Il peut servir à classer certaines informations, mais il ne remplace pas votre régime ni votre activité réelle. Renseignez-vous auprès de l'organisme concerné.
